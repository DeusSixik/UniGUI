# Справочник LayoutStyle и соответствий CSS

`LayoutStyle` описывает, как контейнер должен вычислить размер и положение
виджета. Настройки задаются в коде через цепочку методов. API использует
несколько знакомых из CSS понятий, но не является браузерным CSS: точные
отличия собраны в конце документа.

```java
button.layout(style -> style
        .width(120)
        .height(32)
        .margin(4)
        .flexNone());
```

В таблицах ниже параметры метода записаны в порядке аргументов Java. Значения
размеров `float` задаются в UI-пикселях; проценты передаются числом от `0` до
`100`, например `50` означает 50%. `SizeValue` позволяет явно выбрать `auto`,
пиксели, проценты или размер по содержимому.

Родитель — контейнер, который размещает виджет. Ребёнок — виджет внутри этого
контейнера. В flex-контейнере главная ось идёт вдоль ряда детей, поперечная —
перпендикулярно ему. У `ROW` главная ось горизонтальная, у `COLUMN` — вертикальная.

## Размеры

### `width`, `height`, `size`

Задают желаемую ширину и высоту. Это запрос к родителю, а не обещание итогового
размера: flex-распределение и `min`/`max` могут его изменить. `auto` просит
подобрать размер по содержимому или доступному месту; это не то же самое, что
100%.

| Метод | Параметр | Описание |
| --- | --- | --- |
| `width(SizeValue)` | `width` | Ширина как `auto`, пиксели, процент или размер по содержимому. `null` означает `auto`. |
| `width(float)` | `pixels` | Желаемая ширина в UI-пикселях. Значение `LayoutConstraints.AUTO` из старого API означает `auto`. |
| `widthPercent(float)` | `percent` | Процент от ширины родителя: `50` означает половину, `100` — всю доступную ширину. |
| `height(SizeValue)` | `height` | Высота в формате `SizeValue`. |
| `height(float)` | `pixels` | Желаемая высота в UI-пикселях. |
| `heightPercent(float)` | `percent` | Процент от высоты родителя. |
| `size(SizeValue, SizeValue)` | `width`, `height` | Задаёт обе оси; для каждой можно выбрать свою единицу. |
| `size(float, float)` | `width`, `height` | Задаёт ширину и высоту в UI-пикселях. |
| `sizePercent(float, float)` | `widthPercent`, `heightPercent` | Задаёт ширину и высоту в процентах. |

**CSS:** `width`, `height`, а также процентные значения. Например,
`width: 50%` соответствует `widthPercent(50)`. `SizeValue`-значения содержимого
являются ближайшим аналогом CSS intrinsic sizing, но детали измерения могут
отличаться.

```java
label.layout(style -> style
        .width(SizeValue.fitContent(180))
        .height(SizeValue.auto()));
```

Доступные фабрики `SizeValue`:

| Фабрика | Значение |
| --- | --- |
| `SizeValue.auto()` | Layout выбирает размер по правилам контейнера и содержимому. |
| `SizeValue.px(120)` | Фиксированное значение в UI-пикселях. |
| `SizeValue.percent(50)` | Процент от размера родителя по соответствующей оси. |
| `SizeValue.content()` | Размер по измеренному содержимому. |
| `SizeValue.minContent()` | Минимальный размер, необходимый содержимому. |
| `SizeValue.maxContent()` | Размер, необходимый содержимому без сжатия. |
| `SizeValue.fitContent(180)` | Размер по содержимому, ограниченный указанным пределом. |

### `minWidth`, `minHeight`, `minSize`

Задают нижний предел размера. Ребёнок не должен стать меньше этого значения,
даже если родителю не хватает места. Из-за этого он может выйти за доступную
область.

| Метод | Параметр | Описание |
| --- | --- | --- |
| `minWidth(SizeValue)` | `minWidth` | Минимальная ширина; `auto` снимает явное ограничение. |
| `minWidth(float)` | `pixels` | Минимальная ширина в UI-пикселях. |
| `minWidthPercent(float)` | `percent` | Минимальная ширина как доля ширины родителя. |
| `minHeight(SizeValue)` | `minHeight` | Минимальная высота в формате `SizeValue`. |
| `minHeight(float)` | `pixels` | Минимальная высота в UI-пикселях. |
| `minHeightPercent(float)` | `percent` | Минимальная высота как доля высоты родителя. |
| `minSize(SizeValue, SizeValue)` | `width`, `height` | Устанавливает минимум по обеим осям. |
| `minSize(float, float)` | `width`, `height` | То же, значения в UI-пикселях. |

**CSS:** `min-width` и `min-height`.

### `maxWidth`, `maxHeight`, `maxSize`

Задают верхний предел размера. Растущий элемент остановится на максимуме,
даже если flex-контейнер может предоставить ему больше места. `auto` означает,
что явного верхнего предела нет.

| Метод | Параметр | Описание |
| --- | --- | --- |
| `maxWidth(SizeValue)` | `maxWidth` | Максимальная ширина. |
| `maxWidth(float)` | `pixels` | Максимальная ширина в UI-пикселях. Бесконечность и `NaN` снимают ограничение. |
| `maxWidthPercent(float)` | `percent` | Максимальная ширина как доля ширины родителя. |
| `maxHeight(SizeValue)` | `maxHeight` | Максимальная высота. |
| `maxHeight(float)` | `pixels` | Максимальная высота в UI-пикселях. Бесконечность и `NaN` снимают ограничение. |
| `maxHeightPercent(float)` | `percent` | Максимальная высота как доля высоты родителя. |
| `maxSize(SizeValue, SizeValue)` | `width`, `height` | Устанавливает максимум по обеим осям. |
| `maxSize(float, float)` | `width`, `height` | То же, значения в UI-пикселях. |
| `maxSizePercent(float, float)` | `widthPercent`, `heightPercent` | Максимум по обеим осям в процентах. |

**CSS:** `max-width` и `max-height`.

### `fixed`, `fill`, `expand`

Это короткие методы для распространённых задач. Они задают разные правила и не
заменяют друг друга.

| Метод | Параметр | Описание |
| --- | --- | --- |
| `fixed(float, float)` | `width`, `height` | Задаёт размеры и отключает flex-рост и flex-сжатие. |
| `fill()` | нет | Просит 100% ширины и высоты родителя. Это процентный размер. |
| `expand()` | нет | Занимает остаток свободного места на главной оси flex-родителя. |

**CSS:** `fixed` и `fill` не имеют отдельного CSS-свойства. `fill()` ближе всего
к `width: 100%; height: 100%`. `expand()` задаёт сочетание flex grow/shrink/basis;
практически похожее поведение в CSS обычно задают через `flex`.

```java
VBox panel = new VBox();
header.layout(style -> style.fixed(200, 32));
body.layout(LayoutStyle::expand); // забирает оставшуюся высоту колонки
```

### `aspectRatio`

Задаёт желаемое соотношение ширины к высоте. Оно помогает вычислить одну ось,
если другая задана, а соответствующий размер оставлен `auto`.

| Метод | Параметр | Описание |
| --- | --- | --- |
| `aspectRatio(float)` | `ratio` | Отношение ширины к высоте. Для 16:9 передайте `16.0f / 9.0f`. Нулевое, отрицательное и нечисловое значение отключает соотношение. |

**CSS:** `aspect-ratio`.

## Отступы и переполнение

### `margin`, `marginAuto`

`margin` — внешнее пространство вокруг виджета. Оно отделяет его от соседей.
`marginAuto` отмечает стороны, которым разрешено поглощать свободное место.

| Метод | Параметры | Описание |
| --- | --- | --- |
| `margin(EdgeInsets)` | `insets` | Задаёт отдельные внешние отступы со всех сторон. `null` означает нулевой отступ. |
| `margin(float)` | `all` | Одинаковый отступ сверху, справа, снизу и слева. |
| `margin(float, float)` | `horizontal`, `vertical` | Первый параметр — слева/справа, второй — сверху/снизу. |
| `margin(float, float, float, float)` | `left`, `top`, `right`, `bottom` | Независимый отступ для каждой стороны. |
| `marginAuto(AutoMargins)` | `sides` | Выбирает автоматические стороны. `null` означает отсутствие auto-отступов. |
| `marginAutoHorizontal()` | нет | Включает auto-отступы слева и справа. |
| `marginAutoVertical()` | нет | Включает auto-отступы сверху и снизу. |

**CSS:** `margin` и `margin: auto`. Автоматические отступы распределяют
свободное место и на главной оси могут отменить эффект `justify-content`.

### `padding`

`padding` — пространство внутри виджета, между его краями и дочерним
содержимым. Он уменьшает область, доступную детям.

| Метод | Параметры | Описание |
| --- | --- | --- |
| `padding(EdgeInsets)` | `insets` | Отдельные внутренние отступы со всех сторон. `null` означает нулевой отступ. |
| `padding(float)` | `all` | Одинаковый внутренний отступ со всех сторон. |
| `padding(float, float)` | `horizontal`, `vertical` | Первый параметр — слева/справа, второй — сверху/снизу. |
| `padding(float, float, float, float)` | `left`, `top`, `right`, `bottom` | Независимый внутренний отступ для каждой стороны. |

**CSS:** `padding`.

### `overflow`, `overflowX`, `overflowY`

Определяют, что происходит с дочерним содержимым, которое не помещается в
границы виджета. Прокрутку по этим настройкам предоставляет `ScrollView`.

| Метод | Параметры | Описание |
| --- | --- | --- |
| `overflow(Overflow)` | `overflow` | Один режим для обеих осей. |
| `overflowX(Overflow)` | `overflowX` | Режим для горизонтальной оси. |
| `overflowY(Overflow)` | `overflowY` | Режим для вертикальной оси. |

Варианты `Overflow`:

| Значение | Поведение |
| --- | --- |
| `VISIBLE` | Содержимое рисуется и за границами виджета. |
| `HIDDEN` | Содержимое обрезается без прокрутки. |
| `SCROLL` | `ScrollView` всегда включает прокрутку по выбранной оси. |
| `AUTO` | `ScrollView` включает прокрутку, если содержимое не помещается. |

**CSS:** названия режимов совпадают с `overflow`, `overflow-x` и `overflow-y`,
но прокрутка реализована виджетом `ScrollView`, а не браузером.

## Flex: направление и размеры детей

### `flexDirection`, `flexWrap`, `flexFlow`

`flexDirection` задаёт направление главной оси. `flexWrap` решает, остаются ли
дети на одной линии или переходят на следующую, если места не хватает.

| Метод | Параметры | Описание |
| --- | --- | --- |
| `flexDirection(FlexDirection)` | `direction` | `ROW`, `ROW_REVERSE`, `COLUMN` или `COLUMN_REVERSE`. `null` означает `COLUMN`. |
| `flexWrap(FlexWrap)` | `wrap` | `NOWRAP`, `WRAP` или `WRAP_REVERSE`. `null` означает `NOWRAP`. |
| `flexFlow(FlexDirection, FlexWrap)` | `direction`, `wrap` | Задаёт направление и перенос одной операцией. |

**CSS:** `flex-direction`, `flex-wrap`, `flex-flow`.

### `gap`, `rowGap`, `columnGap`

Задают расстояние между соседними детьми. Это промежуток внутри контейнера,
а не внешний отступ самих виджетов.

| Метод | Параметры | Описание |
| --- | --- | --- |
| `rowGap(float)` | `rowGap` | Вертикальный промежуток между рядами или линиями переноса. |
| `columnGap(float)` | `columnGap` | Горизонтальный промежуток между колонками или детьми в строке. |
| `gap(float)` | `gap` | Одинаковый промежуток по обеим осям. |
| `gap(float, float)` | `rowGap`, `columnGap` | Вертикальный промежуток, затем горизонтальный. |

Отрицательные, бесконечные и `NaN` значения приводятся к нулю.

**CSS:** `gap`, `row-gap`, `column-gap`.

### `flexGrow`, `flexShrink`, `flexBasis`

Эти свойства управляют тем, как ребёнок получает или отдаёт место на главной
оси flex-родителя.

| Метод | Параметры | Описание |
| --- | --- | --- |
| `flexGrow(float)` | `grow` | Вес для деления оставшегося свободного места. `0` — не расти, `2` получает вдвое большую долю, чем сосед с весом `1`. Это вес, не процент. |
| `flexShrink(float)` | `shrink` | Вес, определяющий, насколько ребёнок уступает место при нехватке размера. `0` запрещает автоматическое сжатие. |
| `flexBasis(SizeValue)` | `basis` | Начальный размер ребёнка на главной оси перед распределением свободного места. `auto` использует размер оси или содержимого. |
| `flexBasis(float)` | `pixels` | То же, начальный размер в UI-пикселях или `LayoutConstraints.AUTO` для `auto`. |
| `flex(float, float, SizeValue)` | `grow`, `shrink`, `basis` | Задаёт все три flex-параметра. |
| `flex(float, float, float)` | `grow`, `shrink`, `basisPixels` | То же, начальный размер задан в UI-пикселях. |

**CSS:** `flex-grow`, `flex-shrink`, `flex-basis` и сокращение `flex`.

### `flex`, `flexAuto`, `flexInitial`, `flexNone`, `noShrink`

Сокращения задают готовые сочетания `grow`, `shrink` и `basis`.

| Метод | Аргументы и результат |
| --- | --- |
| `flex(grow)` | `grow`, с `shrink = 1` и `basis = 0%`. Например, `flex(1)` соответствует `flex: 1` в поддерживаемом UniGUI варианте. |
| `flexAuto()` | `1 1 auto`: может расти и сжиматься от своего размера или содержимого. |
| `flexInitial()` | `0 1 auto`: не растёт, но может сжиматься. |
| `flexNone()` | `0 0 auto`: не растёт и не сжимается. |
| `noShrink()` | Устанавливает только `shrink = 0`, сохраняя остальные flex-настройки. |

**CSS:** значения соответствуют распространённым сокращениям `flex: auto`,
`flex: initial` и `flex: none`. `noShrink()` — удобный метод для отдельного
свойства `flex-shrink: 0`.

### `order`

Меняет порядок размещения детей одного родителя. Меньшее число размещается
раньше; при равных значениях сохраняется исходный порядок детей.

| Метод | Параметр | Описание |
| --- | --- | --- |
| `order(int)` | `order` | Целое значение порядка. Отрицательные значения допустимы. По умолчанию `0`. |

**CSS:** `order`.

## Flex: выравнивание

### `justifyContent`

Распределяет группу детей вдоль главной оси, когда после их размещения остаётся
свободное место. При `ROW` это горизонталь, при `COLUMN` — вертикаль.

| Метод | Параметр | Описание |
| --- | --- | --- |
| `justifyContent(Justify)` | `justifyContent` | `START`, `CENTER`, `END`, `SPACE_BETWEEN`, `SPACE_AROUND` или `SPACE_EVENLY`. `null` означает `START`. |

**CSS:** `justify-content`.

### `alignItems`, `alignSelf`

Выравнивают детей по поперечной оси. `alignItems` задаётся на родителе сразу
для детей; `alignSelf` задаётся на ребёнке и переопределяет правило родителя.

| Метод | Параметр | Описание |
| --- | --- | --- |
| `alignItems(Align)` | `alignItems` | Общее выравнивание детей: `START`, `CENTER`, `END`, `BASELINE` или `STRETCH`. `null` означает `STRETCH`. |
| `alignSelf(Align)` | `alignSelf` | Личное выравнивание ребёнка. `AUTO` возвращается к правилу родителя; `null` означает `AUTO`. |
| `center()` | нет | На контейнере центрирует детей и по главной, и по поперечной оси. |
| `centerSelf()` | нет | На ребёнке центрирует только по поперечной оси. |

`Align.STRETCH` растягивает ребёнка по доступной поперечной оси. `Align.BASELINE`
выравнивает текстовые элементы по общей линии текста, если виджет поддерживает
измерение baseline.

**CSS:** `align-items` и `align-self`. `center()` — сокращение, которое задаёт
`align-items: center` и `justify-content: center` на контейнере.

### `alignContent`

Распределяет несколько линий детей по поперечной оси. Имеет смысл, когда перенос
включён и дети заняли больше одной линии. На одной линии действует `alignItems`.

| Метод | Параметр | Описание |
| --- | --- | --- |
| `alignContent(AlignContent)` | `alignContent` | `STRETCH`, `START`, `CENTER`, `END`, `SPACE_BETWEEN`, `SPACE_AROUND` или `SPACE_EVENLY`. `null` означает `STRETCH`. |

**CSS:** `align-content`.

## Grid

`GridBox` — контейнер-сетка. Колонка описывает ширину ячеек по вертикали,
строка — их высоту по горизонтали. Каждый `GridTrack` задаёт размер одной
колонки или строки.

### `gridTemplateColumns`, `gridTemplateRows`

Задают явный список колонок и строк сетки. Можно вызвать методы на `LayoutStyle`
или использовать удобные обёртки `GridBox.gridColumns(...)` и `gridRows(...)`.

| Метод | Параметр | Описание |
| --- | --- | --- |
| `gridTemplateColumns(GridTrack...)` | `tracks` | Размеры колонок по порядку. |
| `gridTemplateColumns(List<GridTrack>)` | `tracks` | То же в виде списка. |
| `gridTemplateRows(GridTrack...)` | `tracks` | Размеры строк по порядку. |
| `gridTemplateRows(List<GridTrack>)` | `tracks` | То же в виде списка. |

Фабрики `GridTrack`:

| Фабрика | Значение |
| --- | --- |
| `GridTrack.px(80)` | Фиксированный размер в UI-пикселях. |
| `GridTrack.percent(50)` | Процент от размера содержимого сетки по этой оси. |
| `GridTrack.fr(1)` | Доля оставшегося свободного места; число задаёт вес доли. |
| `GridTrack.auto()` | Размер подстраивается под размещённое содержимое. |
| `GridTrack.minmax(min, max)` | Ограничивает размер трека между минимумом и максимумом. |
| `GridTrack.repeat(3, track)` | Создаёт список из нескольких одинаковых треков. |

**CSS:** `grid-template-columns` и `grid-template-rows`. Поддерживаемые значения
треков: пиксели, проценты, `fr`, `auto`, `minmax(...)` и `repeat(...)`.

```java
GridBox grid = new GridBox();
grid.gridColumns(GridTrack.px(80), GridTrack.fr(1), GridTrack.fr(2));
grid.gridRows(GridTrack.px(32), GridTrack.auto());
```

### `gridAutoColumns`, `gridAutoRows`, `gridAutoFlow`

Если сетке не хватает явно заданных колонок или строк, она создаёт новые.
`gridAutoColumns` и `gridAutoRows` задают размер таких новых треков;
`gridAutoFlow` определяет, куда сетка сначала помещает следующий ребёнок.

| Метод | Параметры | Описание |
| --- | --- | --- |
| `gridAutoColumns(List<GridTrack>)` | `tracks` | Шаблон размеров автоматически созданных колонок. |
| `gridAutoColumnsOf(GridTrack...)` | `tracks` | То же для набора аргументов; отдельное имя сохраняет однозначность вызова с `null`. |
| `gridAutoRows(List<GridTrack>)` | `tracks` | Шаблон размеров автоматически созданных строк. |
| `gridAutoRowsOf(GridTrack...)` | `tracks` | То же для набора аргументов. |
| `gridAutoFlow(GridAutoFlow)` | `flow` | `ROW`, `COLUMN`, `ROW_DENSE` или `COLUMN_DENSE`. `null` означает `ROW`. |

`ROW` заполняет строку слева направо, затем начинает следующую. `COLUMN`
заполняет колонку сверху вниз, затем переходит к следующей. Режимы `DENSE`
разрешают заполнять ранее пропущенные ячейки.

**CSS:** `grid-auto-columns`, `grid-auto-rows`, `grid-auto-flow`.

### `gridColumn`, `gridRow`

Размещают одного ребёнка в сетке. Номер линии начинается с `1`; значение
`start <= 0` оставляет поиск места сетке. `span` — число занимаемых колонок
или строк.

| Метод | Параметры | Описание |
| --- | --- | --- |
| `gridColumn(int, int)` | `start`, `span` | Начальная линия колонки и число колонок. Значения `span < 1` становятся `1`. |
| `gridRow(int, int)` | `start`, `span` | Начальная линия строки и число строк. Значения `span < 1` становятся `1`. |

**CSS:** `grid-column` и `grid-row`. Например, `gridColumn(2, 2)` соответствует
`grid-column: 2 / span 2`.

## Позиционирование и порядок рисования

### `position`

Выбирает, участвует ли виджет в обычном размещении детей родителя.

| Метод | Параметр | Описание |
| --- | --- | --- |
| `position(PositionType)` | `position` | `STATIC`, `RELATIVE`, `ABSOLUTE` или `FIXED`. `null` означает `RELATIVE`. |

| Значение | Поведение |
| --- | --- |
| `STATIC` | Обычное размещение; значения `left`, `top`, `right`, `bottom` не применяются. |
| `RELATIVE` | Сначала занимает место среди соседей, затем может быть сдвинут. Соседи остаются на местах. |
| `ABSOLUTE` | Не занимает место в обычном потоке и позиционируется относительно родителя. |
| `FIXED` | В текущей версии ведёт себя как `ABSOLUTE` относительно ближайшего layout-хоста. |

**CSS:** `position: static`, `relative`, `absolute`, `fixed`; поведение `FIXED`
в UniGUI отличается от привязки к окну браузера.

### `left`, `top`, `right`, `bottom`, `inset`

Задают расстояние от края родителя до соответствующего края виджета. Обычно
применяются вместе с `ABSOLUTE`; при `STATIC` игнорируются. Значения могут быть
пикселями, процентами или `auto`.

| Метод | Параметры | Описание |
| --- | --- | --- |
| `left(SizeValue)` / `left(float)` | `left` / `pixels` | Расстояние от левого края. |
| `top(SizeValue)` / `top(float)` | `top` / `pixels` | Расстояние от верхнего края. |
| `right(SizeValue)` / `right(float)` | `right` / `pixels` | Расстояние от правого края. |
| `bottom(SizeValue)` / `bottom(float)` | `bottom` / `pixels` | Расстояние от нижнего края. |
| `inset(SizeValue, SizeValue, SizeValue, SizeValue)` | `left`, `top`, `right`, `bottom` | Задаёт все четыре стороны; `null` для каждой стороны означает `auto`. |
| `inset(float)` | `all` | Одинаковое расстояние до всех сторон в UI-пикселях. |
| `inset(float, float)` | `horizontal`, `vertical` | Слева/справа, затем сверху/снизу. |
| `inset(float, float, float, float)` | `left`, `top`, `right`, `bottom` | Все стороны независимо, в UI-пикселях. |

**CSS:** свойства `left`, `top`, `right`, `bottom` и сокращение `inset`.

### `zIndex`

Задаёт порядок рисования относительно детей того же родителя. Дети рисуются
от меньшего значения к большему; проверка нажатия идёт в обратном порядке.

| Метод | Параметр | Описание |
| --- | --- | --- |
| `zIndex(int)` | `zIndex` | Порядок рисования. При равных значениях сохраняется порядок детей у родителя. По умолчанию `0`. |

**CSS:** `z-index`. Вложенные контейнеры UniGUI не полностью повторяют браузерные
изолированные контексты порядка рисования.

## Служебные и старые методы

| Метод | Назначение | CSS-аналог |
| --- | --- | --- |
| `update(Consumer<LayoutStyle>)` | Применяет несколько изменений и вызывает callback изменения один раз после всей группы. | Нет. |
| `onChanged(Runnable)` | Устанавливает callback, который сообщает владельцу об изменении стиля. Обычно используется самим виджетом. | Нет. |
| `copy()` | Создаёт копию значений без callback. | Нет. |
| `copyFrom(LayoutStyle)` | Переносит значения в этот объект, сохраняя его callback. | Нет. |
| `applyLegacyConstraints(LayoutConstraints)` | Переносит значения старого формата ограничений. Метод устарел. | Нет. |
| `toLegacyConstraints(LayoutConstraints)` | Преобразует стиль в старый формат; проценты берутся из `fallback`. Метод устарел. | Нет. |
| `horizontalAlignment(...)`, `verticalAlignment(...)`, `align(...)` | Старое выравнивание для совместимости. В flex-контейнере используйте `alignItems` на родителе и `alignSelf` на ребёнке. | Частичный аналог старого slot-выравнивания. |

## Отличия от CSS

- `LayoutStyle` хранит значения одного виджета. Здесь нет CSS-селекторов,
  каскада, наследования и таблиц стилей.
- `flexShrink` по умолчанию равен `0`; в браузерном CSS обычно `1`.
- `flexDirection` по умолчанию `COLUMN`, тогда как у CSS flex-контейнера обычно
  `row`.
- `alignItems` по умолчанию `STRETCH`, `justifyContent` — `START`.
- `auto` не означает 100%. Для размера родителя используйте проценты; для
  остатка свободного места flex-родителя — `expand()`.
- `position(FIXED)` привязывается к ближайшему layout-хосту, а не к экрану.
- `alignContent` распределяет только несколько линий переноса. Для одной линии
  используйте `alignItems`.
- `overflow` управляет обрезкой, а прокрутка доступна через `ScrollView`.
- Значения `float` для размеров и отступов — UI-пиксели. Масштабирование игрового
  интерфейса выполняется уровнем экрана или контекста.

## Полный пример

Заголовок имеет постоянную высоту, а область содержимого забирает остаток высоты
и прокручивается, если содержимое не помещается:

```java
VBox screen = new VBox();
screen.layout(style -> style
        .padding(8)
        .gap(6));

header.layout(style -> style
        .height(28)
        .flexNone());

content.layout(style -> style
        .expand()
        .minHeight(0)
        .overflowY(Overflow.AUTO));

screen.addChild(header);
screen.addChild(content);
```
