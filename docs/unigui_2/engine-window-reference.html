3. Токены (источник правды)

Те же значения живут в :root выше — эта таблица для сверки с theme-redesign.md.
--bg-0 / --bg-1 / --bg-2Фон: вьюпорт / панели / приподнятое
--bg-hover / --bg-selectedПилюли hover / selected
--border-subtleЕдинственный бордер хрома
--text-hi / -mid / -loТекст: основной / вторичный / приглушённый
--accent / --accent-hoverАкцент и его hover
--dangerDanger-кнопки
--radius-sm / -md / -lg4 / 8 / 12px
--control-h / --pad-x / --popup-gap36px / 12px / 6px — размеры из токенов, не хардкод
