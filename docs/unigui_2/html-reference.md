# HTML+CSS референс главного окна движка

Файл: `engine-window-reference.html` (рядом с этим документом). Однофайловый
эталон без билда и зависимостей: открывается в браузере рядом с TestMod-зеркалом,
расхождения видны глазами, споры «красиво / некрасиво» заменяются пикселями.

## 1. Shell главного окна (в духе Unreal/Unity/Unigine)

```
+------------------------------------------------------------------+
| Меню: Файл  Окна  Инструменты  Помощь              [лупа]        |
+--------+--------------------------------------------+------------+
| rail   | Табы: [Окно игры x][scene.rig x][montage x]| Инспектор  |
| icons  +--------------------------------------------+  - числ.   |
|        |                                            |    поля    |
|        |   Вьюпорт-заглушка (сетка + модель-        |  - кнопки  |
| Scene  |   плейсхолдер) + тулбар                    |  - toggle- |
| дерево |                                            |    пара    |
|        |                                            |  - danger  |
+--------+--------------------------------------------+------------+
| Таймлайн-заглушка: транспорт, линейка, 2-3 дорожки с клипами     |
+------------------------------------------------------------------+
```

- Менюбар: пункты + разделители + hover-подсветка + правый слот (поиск).
- Левый рейл иконок (3–4 кнопки) + панель «Сцена» с деревом
  (раскрывашки, иконки глаз/замок, selected-пилюля).
- Стрип табов: иконка + текст + крестик, активный таб — синее подчёркивание.
- Центр: тёмная подложка с CSS-сеткой (repeating-linear-gradient) и
  плейсхолдером модели + плавающий тулбар (play/orbit/expand).
- Правый инспектор: заголовок, числовые поля, подписи, info-иконки, кнопки
  («Добавить правило»), сегментированная пара («Повторить» / «К событию» +
  иконка корзины), поле выражения с подсветкой, красная danger-кнопка.
- Низ: таймлайн-заглушка — транспорт, время, линейка с тиками, синяя головка,
  2–3 дорожки с цветными клипами (синий/зелёный/фиолетовый/оранжевый),
  ромбики кейфреймов, глазки/замки слева, скроллбар.

## 2. Витрина состояний dropdown (ключевая часть)

Отдельная секция, все состояния рядом:

- Закрытый хедер: текст слева + шеврон справа, паддинг 12px, высота 36px.
- Открытый: шеврон вверх + попап с зазором 6px от хедера.
- Строки: normal / hover-пилюля / selected-пилюля / disabled.
- Вложенное меню как на референсе Hollow: строки «label слева — value
  справа — шеврон», слайдер-строка, строки-пресеты (Morning 06:00...),
  чекбокс-строка («Day and night cycle»), разделители.
- Демо-контент витрины: темы (Dark / Light / High Contrast / Minecraft) —
  заодно витрина будущих тем движка.

## 3. Токены (фиксируются здесь первыми, потом едут в код)

```css
:root {
  --bg-0: #14161a;        /* самый тёмный фон, вьюпорт */
  --bg-1: #1e2126;        /* панели */
  --bg-2: #23262c;        /* приподнятые поверхности, хедеры */
  --bg-hover: #2a2f37;    /* hover-пилюля */
  --bg-selected: #26405e; /* selected-пилюля */
  --border-subtle: #2e333b;
  --text-hi: #e8eef4;
  --text-mid: #9aa4b0;
  --text-lo: #5f6772;
  --accent: #4a9eff;
  --accent-hover: #63adff;
  --danger: #e5484d;
  --radius-sm: 4px;
  --radius-md: 8px;
  --radius-lg: 12px;
  --control-h: 36px;
  --pad-x: 12px;
  --popup-gap: 6px;
  --clip-blue: #3d6a99;
  --clip-green: #5d8a4a;
  --clip-purple: #7a5f9e;
  --clip-orange: #b07a3e;
}
```

Правила, которые фиксирует референс (и которые потом проверяем в движке):
- selected/hover — всегда пилюля с внутренними отступами, никогда full-bleed;
- шеврон/иконки — отдельный слот справа, не пробелом в тексте;
- попап отделён зазором, свой радиус, строки с паддингами;
- высота контролов и паддинги — из токенов, не захардкожены.

## 4. Зеркало в TestMod

`EngineWindowDemoScreen` на `DemoScaffold`: тот же layout теми же виджетами
(`MenuBar`, `TreeView`, `TabControl`, `TextInput`/`NumberField`, `Button`,
`ToggleButton`, `DropDownBox`/`ComboBox` с меню-контентом: слайдер + пресеты +
чекбокс). Демо-данныеDropdown — те же 4 темы. Критерий готовности: скриншот
зеркала рядом с HTML не отличим по структуре и отступам (цвета — после
перевода на токены из `theme-redesign.md`).
