# TreeView refresh (unigui_2)

Строка дерева больше не рисует unicode-маркер (`▾`/`▸`) внутри текста и не
заливает selected на всю ширину циановой рамкой.

## Строка

- Высота 28, шаг глубины 18, радиус пилюли 4 (`--radius-sm`).
- Пилюля с инсетом 4×1: selected `#26405e` перекрывает hover `#2a2f37`.
  Обычная строка без hover фона не рисует.
- Disclosure — два stroke-отрезка в слоте 14px. Слот резервируется у
  каждой строки, иначе лист без шеврона встаёт вровень с родителем.
  Глиф только у узла с детьми: вниз если раскрыт, вправо если свёрнут.
  Цвет `--text-lo`.
- Иконка в слоте 16px, слот не резервируется если иконки нет.
  Приоритет: `TreeViewNode.iconDraw` → `icon(TextureHandle)` → глиф режима.
  `noIcon()` гасит иконку узла совсем. Цвет глифа `--text-mid`.
- Текст строки — только подпись узла. Цвет: selected `--text-hi`, обычный
  `--text-mid`, невыбираемый `--text-lo`.
- Hover-прокрутка длинной подписи сохранена; клип начинается после слотов.

`XmlHierarchyPanel` свой disclosure не трогает.

## Режимы

`TreeView.iconMode`:

- `FOLDERS` (по умолчанию) — папка у ветки, файл у листа.
- `NONE` — только шеврон и текст, как дерево сцены.

Демо показывает оба: `TreeView` в `FOLDERS`, `TreeList` в `NONE`.

## Тест

`testTreeViewContracts` ждёт чистый текст и отступ: X текста `Leaf` правее
`Child`, `Child` правее `Root`. Шевроны считаются по цвету `--text-lo`:
6 отрезков на раскрытом кадре и 6 после сворачивания Child.
`iconMode(NONE)` убирает глифы папок и файлов.
