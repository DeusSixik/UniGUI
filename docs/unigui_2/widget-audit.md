# Аудит виджетов: матрица, нейминг, логика

Процесс: для каждого виджета — строка в матрице, расхождения чиним по ходу
обновления хрома. Отдельно копятся несоответствия логики и названий:
переименовывать только с депрекейтом, не ломая API молча.

## Матрица (шаблон строки)

| Референс-элемент | Наш виджет | Гэп |
|---|---|---|
| Dropdown закрыт/открыт/hover/selected | `DropDownBox` + `ComboBox` | хром: пилюли, зазор попапа, шеврон слотом; размеры из токенов |
| Вложенное меню (слайдер, пресеты, чекбокс) | `Popup` + произвольный контент | хром попапа; готовых строк «label—value—шеврон» нет |
| Дерево сцены | `TreeView` | ок, проверить отступы/пилюлю против референса |
| Табы с крестиками | `TabControl` | таб с крестиком собирается вручную — нужен готовый closable-вариант |
| Инспектор (поля, toggle-пара, danger) | `TextInput`, `Button`, `ToggleButton` | danger-стиль, сегментированная пара |
| Таймлайн | — | нового виджета нет; отдельный проект после этого цикла |

## Разобранный пример: DropDownBox

Файл: `common/.../widgets/interaction/DropDownBox.java`. Логика живая,
лечить надо хром и размеры:

- `HEADER_HEIGHT = 22.0f` захардкожена → высота из токена (`--control-h`).
- `CONTENT_INSET = 2.0f`, `radius(3.0f)` → токены отступов/радиусов.
- Циановая рамка `borderColor().set(0.25, 0.78, 1.0, 0.75)` — legacy-дефолт,
  заменить на `border-subtle` из темы.
- Стрелка — inline-треугольник + ведущий пробел (`createHeaderArrow`) →
  шеврон слотом справа через layout.
- Selected/hover строк — решает контент (`ComboBox` option-кнопки):
  перевести на пилюли с внутренними отступами.
- Цвета `0.025/0.030/0.040` в конструкторе → токены `bg-1/surface`.
- Попап без зазора → `popup-gap` между хедером и хостом.

## Несоответствия логики и названий (копилка)

1. `DropDownBox` vs `ComboBox` vs `ComboBox.DropDownMode` — три сущности про
   одно раскрытие; `DropDownBox` ссылается на тип `ComboBox` ради enum'а.
   Кандидат: единый enum режима + чёткое разделение (host generic /
   selectable list).
2. `headerText` / `richHeaderText` — дублирующаяся пара геттеров/сеттеров.
3. `dropDownWidth` / `dropDownMatchesWidgetWidth` / `dropDownSameWidth` /
   `autoDropDownWidth` — четыре способа задать ширину; свернуть к
   `width(mode, value)`.
4. `themeEnabled(false)` как способ «не трогай мои цвета» — уйдёт само после
   новой системы тем (`theme-redesign.md`): заменится на override/explicit.
5. `Popup.anchor` + `contentHost` + `contentScroll` + `dropDownPopup` — четыре
   вложенности ради списка; проверить, что здесь нет legacy-наследства,
   которое можно спрямить без смены поведения.

Правила переименований: новое имя + `@Deprecated` мост минимум на релиз,
XML-имена (`@XmlWidgetName`) не менять без мигратора.
