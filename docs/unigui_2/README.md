# UniGUI 2.0 — освежение UI

Цель: вывести базовый вид виджетов на уровень современных Modern UI (референс —
HollowEngine UI и главные окна игровых движков в духе Unigine / Unity / Unreal).
Не копирование чужого вида, а лечение собственных болезней: хром, типографика,
отступы, темы.

Причина: текущий вид виджетов проигрывает современным UI. Диагноз по скриншотам:
теснота (захардкоженные высоты вроде `HEADER_HEIGHT = 22.0f`), радиус 3px +
циановая рамка из эпохи legacy, selected заливкой на всю ширину вместо «пилюли»,
стрелка пробелом вместо слота справа, цвета россыпью по конструкторам
(`background().set(0.025, 0.030, 0.040, ...)` в каждом виджете).

## Документы

1. [`html-reference.md`](html-reference.md) — план HTML+CSS референса:
   однофайловый эталон главного окна движка + витрина состояний dropdown.
2. [`widget-audit.md`](widget-audit.md) — процесс аудита виджетов: матрица
   «референс → наш виджет → гэп», несоответствия логики и названий,
   разобранный пример `DropDownBox`.
3. [`theme-redesign.md`](theme-redesign.md) — проект новой системы тем:
   диагноз текущей Style + Theme, токены, приоритет резолва, API-скетч, миграция.
4. [`style-token-layer.md`](style-token-layer.md) — контракт неизменяемых
   токенов, порядок резолва, версии и обязательный пользовательский пример.

## Порядок работ

1. HTML+CSS референс (фундамент: токены, shell, витрина dropdown) → `html-reference.md`.
2. Зеркало в TestMod (`EngineWindowDemoScreen` на `DemoScaffold`) — открыть рядом
   с браузером, расхождения видны глазами.
3. Контракт слоя токенов → `style-token-layer.md`.
4. Токены темы + резолвер в коде → `theme-redesign.md`.
5. Inline Style API и каскад правил → `style-api.md`, затем перевод `SurfaceWidget` / `Button` / `TextInput` (80% картинки), затем
   DropDown/Popup хром, затем остальное по аудиту.
6. Таймлайн — отдельный новый виджет, вне этого цикла (см. `widget-audit.md`).
