# PageView / Carousel refresh (unigui_2)

`PageView` хрома не получил и не должен: он только держит страницы и
показывает ровно одну. Навигация живёт в `Carousel`.

## Carousel

- Страницы сверху, навигация снизу.
- Кнопки — штриховые шевроны влево/вправо, как disclosure в `TreeView`.
  Букв `<` / `>` в отрисовке нет. Размер 28×28, радиус 4.
- Посередине ряд точек (`Carousel.dots()`): активная — акцент `#4a9eff`,
  остальные — `--text-lo`. Клик по точке выбирает страницу.
- Текст `1 / 3` сохранён в `indicator()`, но метка `COLLAPSED`: на экране
  её нет, `indicator().text()` для контрактов и XML работает.

## Demo

Секция `Carousel / PageView / View` показывает оба:
- `Carousel` 320×150 с тремя страницами, точками и стрелками;
- голый `PageView` 320×96 с внешними кнопками Previous/Next и счётчиком.
